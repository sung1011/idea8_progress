# 上班鼓励器

菜单栏里的本地工时计薪器。点一下菜单栏图标，就能看到今天赚了多少、现在的速度、今天的工时进度，以及本月累计。

应用是 macOS 菜单栏代理（`LSUIElement`）：运行后没有 Dock 图标，也不会占着主窗口。数据只写在本机 `UserDefaults` 里。

- 显示名称：上班鼓励器
- Bundle ID：`com.sung1011.idea8progress`
- 系统要求：macOS 13 或更高
- 工程：`idea8Progress.xcodeproj`（SwiftUI，可在 Apple Silicon 上的 Xcode 直接打开）

## 用 Xcode 打开并运行

1. 安装 Xcode 15 或更高版本。
2. 双击仓库根目录的 `idea8Progress.xcodeproj`。
3. 顶部方案选 `idea8Progress`，运行目标选 `My Mac`。
4. 如果签名失败：选中 `idea8Progress` target → Signing & Capabilities → Team 选你的 Apple ID。只在本机调试时，用 “Sign to Run Locally” 即可。
5. 按 `⌘R` 运行。
6. 看屏幕**顶部菜单栏**（右边状态图标那一排），会出现 `¥金额` 和一个播放/暂停图标。Dock 里不会出现图标。
7. 点这个图标打开面板。MacBook 刘海如果挡住了图标，按住 `⌘` 再拖动菜单栏图标。
8. 要退出应用，用面板底部的「退出」。停掉 Xcode 的 Run 也会退出。

单元测试：`⌘U`。规则都在 `idea8ProgressTests/earningsChecks.swift`。

## 面板上的四个数

设：

- 净带薪小时 =（下班 − 上班）− 与午休重叠的部分
- 折算时薪
  - 时薪模式：你填的时薪
  - 月薪模式：月薪 ÷（本月勾选的工作日天数 × 净带薪小时）
- 今日有效秒数：今天「计时器开着」的时间段，再和带薪窗口求交集

| 指标 | 怎么算 |
| --- | --- |
| 今日已赚 | 折算时薪 × 今日有效秒数 ÷ 3600 |
| 速度 | 此刻正在入账时等于折算时薪，否则为 0 |
| 工时进度 | 今日有效秒数 ÷ 一个满勤日的净带薪秒数 |
| 本月累计 | 本月今天之前的工作日数 × 一日满勤金额 + 今日已赚 |

一日满勤金额 = 折算时薪 × 净带薪小时。

本月工作日天数按**整月**算，包含今天和还没到的工作日，用来把月薪摊开。已经过去的工作日按满勤补进本月，不看那天实际开了多久计时器。今天不算满勤，只算计时器累计。

## 计时规则

同时满足下面两条，这一秒才入账：

1. 计时器处于「计时中」
2. 这一秒落在带薪窗口里：今天是勾选的工作日，在上班到下班之间，并且不在午休

所以：

- 点了「停止计时」，哪怕人还坐在工位上，也不再增加
- 午休、上班前、下班后，计时器可以开着，但速度是 0，今日已赚不动
- 没勾选的星期（默认周六、周日）同样不计
- 计时状态会保存。退出时如果还是「计时中」，下次打开会把离开期间落在带薪窗口里的时间补上。不想继续算，退出前先停止

已过工作日的「满勤补算」和今天的计时是两套数：昨天即使只开了 10 分钟，本月累计里昨天仍按一整天算；今天则只算实际计时和带薪窗口的交集。

## 默认排班

可以在面板里改，不改的话是：

- 工作日：周一到周五
- 上班 10:00，下班 20:30（本地时间）
- 午休 12:00–14:00，这段不计入带薪时间
- 净带薪工时：10.5 小时 − 2 小时 = **8.5 小时**

上下班和午休都是同一天内的时间。改完之后，今天的计时会按新窗口重算，已过工作日的满勤金额也会跟着新的净工时变。

默认金额只是占位，请改成自己的：月薪 15000 元，时薪 100 元/小时。当前没选中的那一项也会记住，切换模式不会丢掉。

## 怎么验证

### 自动

在 Xcode 里按 `⌘U`。覆盖了这些行为：

- 默认净工时是 8.5 小时，午休从窗口里扣掉
- 计时关闭时，即使时刻还在上班时间内，今日已赚和速度也不增加
- 午休、班次外、非工作日不开收入
- 跨过午休的一段计时，只计午休两边
- 已过工作日按满勤，不按那天真实计时
- 今天不会被再加一份满勤
- 2026 年 11 月按默认排班有 21 个工作日；月末如果今天也上满，本月累计等于月薪

### 手动（任意时刻都能做）

1. 打开面板，确认周一到周五是选中的，上班 10:00、下班 20:30、午休 12:00–14:00，底部写着每日净带薪 8.5 小时。
2. 计薪方式改成「时薪」，时薪填 `3600`（每秒 1 元，方便看）。
3. 保持「未计时」，等几秒。今日已赚不变，速度是 `¥0.00/小时`。
4. 为了不依赖现在是不是上班时间：把「上班」改到当前时间的 1 小时前，「下班」改到 2 小时后，午休改成 `00:00–00:30`（不要盖住现在），并确认今天的星期是勾上的。
5. 点「开始计时」。状态应变成「计时中」。大约 5 秒后，今日已赚约 `¥5.00`，速度是 `¥3,600.00/小时`，工时进度的时分秒在走。
6. 把午休改成盖住当前时间。状态变成「计时中 · 当前不计入收入」，速度回到 0，工时进度停住。
7. 点「停止计时」，再把午休移开。即使现在落在上班时间内，今日已赚也不再增加。
8. 把排班改回默认（10:00–20:30，午休 12:00–14:00）。日满勤应显示 `¥30,600.00`（3600 × 8.5）。本月累计 = 这个金额 × 面板上的「已过工作日」天数 + 今日已赚。今天本身不在那个天数里。

月薪可以另做一次：切回「月薪」，金额填 `17850`，排班保持默认。2026 年 11 月是 21 个工作日，折算时薪应是 `¥100.00/小时`，日满勤 `¥850.00`。其它月份工作日天数不同，时薪会跟着变，这是预期行为。
